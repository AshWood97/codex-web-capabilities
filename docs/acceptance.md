## 完成标准与边界

普通 CR、持续协作、研究、图像一直使用原生 Chrome。完整模式沿用上游独立 Browser + task-bound tool broker，因此需要独立登录和工具授权；不复制 Chrome cookies、profile 或主账号 auth。没有用模型 API、私有 HTTP 或未授权接口回退。

任务结果必须属于当前绑定会话和用户轮次，生成停止，正文/引用/图像两次稳定观察间隔至少 15 秒。研究还要有真正研究模式与本轮完整报告；图像必须是当前轮次可打开的原文件，继续执行路径、格式、尺寸、重复和数量校验。状态服务器信任授权 Codex 的观察，不能独立证明网页内容。

完整 agent 需要真实工具事件、文件 diff 与终端测试结果；`prepare`、配置写入、进程退出成功和 DEV 模拟工具均不满足该标准。审批、沙箱、模型路由和后来用户字段必须保留；未知是否执行过的写操作不得自动重放。后续任务按 [接力计划](plans/2026-10-16-agent-handoff.md) 继续，避免重复已完成验收。
