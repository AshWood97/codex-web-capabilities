## 实现边界

默认流程是 Codex 技能驱动原生 Browser Use/WebMCP，本地 MCP 不在后台控制浏览器。完整模式复用上游原生工具 broker，不执行网页普通文本中的 shell。参考项目多为设计借鉴，具体模块在本项目重新实现；没有宣称将每个 fork 所有特性全部移植。Evanlau 的 30 分钟保留已存在于所选上游，不重复 patch。

账户、页面模式与页面工具会变化。未知模型标识明确标注未知；没有使用模型 API 回退。秘密扫描为启发式过滤，无法保证识别所有秘密。状态服务器相信已授权 Codex 控制器提供的 UI 观察，它不能独立证明屏幕内容；原生浏览器证据和本地代码核验仍是验收的一部分。
